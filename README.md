# AI Scholarship Management System

A full-stack capstone project for discovering scholarships, generating AI-assisted recommendations, managing documents, tracking applications, and providing administrator reporting.

## Architecture
- Frontend: React + Vite
- Backend: Node.js + Express + MongoDB
- ML service: FastAPI
- Authentication: JWT

## Modules
1. Scholarship Discovery & Search
2. AI Recommendation Engine
3. Document Management
4. Admin & Reporting

## Local setup
See each service directory for environment variables and commands.
